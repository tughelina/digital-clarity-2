## Make your digital space easier to use

- Find files through clear topics and searchable names.
- Turn scattered downloads into a shallow folder structure.
- Keep document versions together where you can find them.
- Decide which tabs to keep, close, bookmark, or turn into tasks.
- Give bookmarks a simple, useful home.

Suggestions come from what your assistant can actually inspect, within the area you permit. Example topics: **AI Blog**, **Spirituality Blog**, **Video Raw Files**, **Accounting**.

## You stay in control

**ASK PERMISSION → REVIEW → RECOMMEND → GET APPROVAL → ORGANIZE → REPORT**

1. **Ask permission:** Choose the exact folder, drive/cloud area, or browser to review.
2. **Review:** Inspect the actual items. Clearly identify access limits and uncertainty.
3. **Recommend:** See proposed folders, filenames, tab decisions, and bookmark changes.
4. **Get approval:** Approve the concrete plan or selected actions.
5. **Organize:** Apply only approved changes with available tools.
6. **Report:** Check results and show what changed, what remains, and restoration details.

### Built-in safeguards

- Permission to inspect never counts as approval to change things.
- No moves, renames, folder creation, tab closures, or bookmark edits before approval.
- Duplicate and alternate versions stay beside the main document, with clear names.
- Potentially unnecessary files go to a proposed **DELETE ARCHIVE**, after approval.
- Questionable files are never permanently deleted. No automatic archive purge.
- Existing files are never overwritten. Uncertain items stay unchanged.

These are instructions for the assistant, not a technical security boundary. Review its proposed actions and use your usual backups.

## Install

### Codex

Download the [repository ZIP](https://github.com/tughelina/digital-clarity-2/archive/refs/heads/main.zip), extract it, and copy the inner **digital-clarity-2** folder into:

```text
~/.codex/skills/digital-clarity-2/SKILL.md
```

Alternatively, ask Codex's skill installer:

```text
Install the skill at https://github.com/tughelina/digital-clarity-2/tree/main/digital-clarity-2
```

Reload Codex if the new skill is not listed. Installation does not grant file or browser access.

### Other AI assistants

This is a Markdown instruction skill with YAML metadata, not an app or browser extension. Assistants supporting this skill format may accept the folder through their own installation process. Compatibility has not been tested across products.

For a manual workflow, provide [SKILL.md](digital-clarity-2/SKILL.md) as instructions in your assistant. Direct organization requires suitable tools and permissions. Without them, the assistant can review information you provide and guide you through manual changes. It cannot inspect your computer simply because you uploaded the skill.

## Start here

Tell your assistant:

> Use Digital Clarity 2. Help me organize my Downloads folder. Ask permission before inspecting it, then show me your plan before changing anything.

In Codex, you can invoke it as `$digital-clarity-2`.
